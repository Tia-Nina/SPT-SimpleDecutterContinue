# SimpleDeClutterContinue

SPT Clutter Remover, continued from `somtam.SimpleDeClutter` (Simple Declutterer),
forked from https://github.com/Xenoxia8953/Tyrian-DeClutterer

Working for SPT 4.1 (client 0.16.9.5), with working Decal De-Clutter.

- Plugin GUID: `net.ttfl.spt.SimpleDeClutterContinue`
- Plugin name: `SimpleDeClutterContinue`
- Version: 1.1.0

Note: the plugin GUID changed from `somtam.simple.declutter`, so the BepInEx config
file is now `net.ttfl.spt.SimpleDeClutterContinue.cfg` and will be created with
defaults on first launch.
